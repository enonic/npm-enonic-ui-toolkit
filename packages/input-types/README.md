# @enonic/input-types

XP's input types as Preact components, and the form that composes them from a schema.

Separate from `@enonic/ui-kit` because the audience is narrower and the dependency runs one way: a
form is a screen element, but XP's schema model is a domain the rest of the toolkit knows nothing
about.

Part of [the Enonic UI toolkit](../../README.md); see
[`docs/architecture.md`](../../docs/architecture.md) for what belongs where.
